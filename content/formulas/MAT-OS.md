## Števila in računanje

| | |
|---|---|
| Vrstni red računanja | oklepaji → potence → množenje in deljenje → seštevanje in odštevanje |
| Zakon o zamenjavi | $a + b = b + a$, $\; a \cdot b = b \cdot a$ |
| Zakon o združevanju | $(a + b) + c = a + (b + c)$, $\; (a b) c = a (b c)$ |
| Zakon o razčlenjevanju | $a (b + c) = a b + a c$ |
| Seštevanje ulomkov | $\dfrac{a}{b} + \dfrac{c}{d} = \dfrac{a d + b c}{b d}$ |
| Množenje ulomkov | $\dfrac{a}{b} \cdot \dfrac{c}{d} = \dfrac{a c}{b d}$ |
| Deljenje ulomkov | $\dfrac{a}{b} : \dfrac{c}{d} = \dfrac{a}{b} \cdot \dfrac{d}{c}$ |
| Potence | $a^m \cdot a^n = a^{m+n}$, $\; a^m : a^n = a^{m-n}$, $\; (a^m)^n = a^{m n}$, $\; (a b)^n = a^n b^n$ |
| Desetiške potence | $3{,}2 \cdot 10^{5} = 320\,000$, $\; 10^0 = 1$ |
| Kvadratni koren | $\sqrt{a \cdot b} = \sqrt{a} \cdot \sqrt{b}$, $\; \sqrt{a^2} = a$ za $a \ge 0$ |

## Sorazmerja in odstotki

| | |
|---|---|
| Delež (odstotek) | $d = o \cdot \dfrac{p}{100}$ ($o$ osnova, $p$ odstotki, $d$ delež) |
| Osnova | $o = \dfrac{d \cdot 100}{p}$ |
| Povečanje za $p\,\%$ | $o \cdot \left(1 + \dfrac{p}{100}\right)$; zmanjšanje: $o \cdot \left(1 - \dfrac{p}{100}\right)$ |
| Premo sorazmerje | $\dfrac{y}{x} = k$ oziroma $y = k x$ |
| Obratno sorazmerje | $x \cdot y = k$ |
| Razmerje | $a : b = (k a) : (k b)$ |

## Algebra in funkcije

| | |
|---|---|
| Kvadrat vsote | $(a + b)^2 = a^2 + 2 a b + b^2$ |
| Kvadrat razlike | $(a - b)^2 = a^2 - 2 a b + b^2$ |
| Razlika kvadratov | $a^2 - b^2 = (a - b)(a + b)$ |
| Linearna funkcija | $y = k x + n$ ($k$ smerni koeficient, $n$ začetna vrednost) |
| Smerni koeficient | $k = \dfrac{y_2 - y_1}{x_2 - x_1}$ |
| Ničla | $x_0 = -\dfrac{n}{k}$ |
