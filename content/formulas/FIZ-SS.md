## Kinematika

| | |
|---|---|
| Enakomerno gibanje | $s = v t$ |
| Enakomerno pospešeno | $v = v_0 + a t$, $\; s = v_0 t + \dfrac{a t^2}{2}$, $\; v^2 = v_0^2 + 2 a s$, $\; s = \dfrac{(v_0 + v) t}{2}$ |
| Navpični met | $v = v_0 - g t$, $\; h = v_0 t - \dfrac{g t^2}{2}$, $\; h_{\max} = \dfrac{v_0^2}{2 g}$ |
| Vodoravni met | $x = v_0 t$, $\; y = \dfrac{g t^2}{2}$ |
| Poševni met | $v_x = v_0 \cos \alpha$, $\; v_y = v_0 \sin \alpha - g t$, domet $D = \dfrac{v_0^2 \sin 2\alpha}{g}$ |
| Kroženje | $v = \dfrac{2 \pi r}{t_0} = \omega r$, $\; \omega = \dfrac{2 \pi}{t_0} = 2 \pi \nu$, $\; a_r = \dfrac{v^2}{r} = \omega^2 r$ |

## Dinamika

| | |
|---|---|
| Newtonov zakon | $\vec{F} = m \vec{a}$ |
| Gibalna količina | $\vec{G} = m \vec{v}$, $\; \vec{F} \Delta t = \Delta \vec{G}$ |
| Trenje | $F_{tr} = k_{tr} F_N$ |
| Radialna sila | $F_r = \dfrac{m v^2}{r}$ |
| Gravitacijski zakon | $F = \dfrac{G m_1 m_2}{r^2}$, $\; g = \dfrac{G M}{r^2}$ |
| Navor | $M = r F \sin \varphi$; ravnovesje: $\sum \vec{F} = 0$, $\sum M = 0$ |
| Hookov zakon | $F = k x$ |

## Energija

| | |
|---|---|
| Delo | $A = F s \cos \varphi$ |
| Energije | $W_k = \dfrac{m v^2}{2}$, $\; W_p = m g h$, $\; W_{pr} = \dfrac{k x^2}{2}$ |
| Izrek | $A_{\text{zun}} = \Delta W_k + \Delta W_p + \Delta W_{pr}$ |
| Moč, izkoristek | $P = \dfrac{A}{t} = F v$, $\; \eta = \dfrac{A_{\text{kor}}}{A_{\text{vl}}}$ |
| Tlak, vzgon | $p = \dfrac{F}{S}$, $\; p = \rho g h$, $\; F_{vz} = \rho_t g V$ |

## Toplota

| | |
|---|---|
| Raztezanje | $\Delta l = \alpha l \Delta T$, $\; \Delta V = \beta V \Delta T$ |
| Plinska enačba | $p V = n R T = \dfrac{m}{M} R T$, $\; \dfrac{p V}{T} = \text{konst.}$ |
| Toplota | $Q = m c \Delta T$, taljenje $Q = m q_t$, izparevanje $Q = m q_i$ |
| 1. zakon termodinamike | $\Delta W_n = A + Q$ |
| Delo plina | $A = -p \Delta V$ (pri stalnem tlaku) |
| Toplotni stroj | $\eta = \dfrac{A}{Q_{\text{dov}}}$, $\; \eta_{\max} = 1 - \dfrac{T_2}{T_1}$ |
| Prevajanje, sevanje | $P = \lambda S \dfrac{\Delta T}{d}$, $\; j = \sigma T^4$ |

## Elektrika in magnetizem

| | |
|---|---|
| Coulombov zakon | $F = \dfrac{e_1 e_2}{4 \pi \varepsilon_0 r^2}$ |
| Polje, napetost | $E = \dfrac{F}{e}$, $\; U = E d$, $\; A = e U$ |
| Kondenzator | $C = \dfrac{e}{U}$, $\; C = \dfrac{\varepsilon \varepsilon_0 S}{d}$, $\; W = \dfrac{C U^2}{2}$ |
| Tok, upor | $I = \dfrac{e}{t}$, $\; U = R I$, $\; R = \dfrac{\zeta l}{S}$, $\; P = U I = I^2 R$ |
| Vezave uporov | zaporedno $R = R_1 + R_2$, vzporedno $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ |
| Magnetna sila | $F = I l B \sin \varphi$, $\; F = e v B \sin \varphi$ |
| Gostota polja | dolga tuljava $B = \dfrac{\mu_0 N I}{l}$, ravni vodnik $B = \dfrac{\mu_0 I}{2 \pi r}$ |
| Indukcija | $\Phi = B S \cos \varphi$, $\; U_i = -\dfrac{\Delta \Phi}{\Delta t}$, $\; U_i = l v B$ |
| Transformator | $\dfrac{U_1}{U_2} = \dfrac{N_1}{N_2}$ |
| Izmenični tok | $U_{ef} = \dfrac{U_0}{\sqrt{2}}$, $\; I_{ef} = \dfrac{I_0}{\sqrt{2}}$ |

## Nihanje, valovanje, optika

| | |
|---|---|
| Nihanje | $x = x_0 \sin \omega t$, $\; t_0 = 2 \pi \sqrt{\dfrac{m}{k}}$, nihalo $t_0 = 2 \pi \sqrt{\dfrac{l}{g}}$ |
| Valovanje | $c = \lambda \nu$, $\; \nu = \dfrac{1}{t_0}$ |
| Hitrost na vrvi | $c = \sqrt{\dfrac{F}{\mu}}$ |
| Lomni zakon | $\dfrac{\sin \alpha}{\sin \beta} = \dfrac{c_1}{c_2} = \dfrac{n_2}{n_1}$ |
| Leča, zrcalo | $\dfrac{1}{f} = \dfrac{1}{a} + \dfrac{1}{b}$, $\; \dfrac{S}{P} = \dfrac{b}{a}$, zrcalo $f = \dfrac{r}{2}$ |
| Uklonska mrežica | $d \sin \varphi = N \lambda$ |
| Dopplerjev pojav | $\nu' = \nu \dfrac{c \pm v_o}{c \mp v_i}$ (zgornji predznak: opazovalec in izvor se približujeta) |
