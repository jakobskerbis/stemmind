## Gibanje

| | |
|---|---|
| Hitrost | $v = \dfrac{s}{t}$ |
| Povprečna hitrost | $\bar{v} = \dfrac{s_{\text{celotna}}}{t_{\text{celoten}}}$ |
| Pospešek | $a = \dfrac{\Delta v}{\Delta t}$ |
| Enakomerno pospešeno (iz mirovanja) | $v = a t$, $\; s = \dfrac{a t^2}{2}$ |
| Prosti pad | $v = g t$, $\; h = \dfrac{g t^2}{2}$ |
| Pretvorba hitrosti | $1\,\dfrac{\text{m}}{\text{s}} = 3{,}6\,\dfrac{\text{km}}{\text{h}}$ |

## Sile, gostota, tlak

| | |
|---|---|
| Gostota | $\rho = \dfrac{m}{V}$ |
| Teža | $F_g = m g$ |
| Newtonov zakon | $F = m a$ (rezultanta sil) |
| Prožna vzmet | $F = k x$ ($x$ raztezek) |
| Ravnovesje na vzvodu | $F_1 r_1 = F_2 r_2$ |
| Tlak | $p = \dfrac{F}{S}$ |
| Hidrostatični tlak | $p = \rho g h$ |
| Vzgon | $F_{vz} = \rho_{\text{tek}}\, g\, V_{\text{izp}}$ |
| Telo plava | $\rho_{\text{telesa}} < \rho_{\text{tekočine}}$ |

## Delo, energija, moč

| | |
|---|---|
| Delo | $A = F s$ |
| Kinetična energija | $W_k = \dfrac{m v^2}{2}$ |
| Potencialna energija | $W_p = m g h$ |
| Moč | $P = \dfrac{A}{t}$ |
| Izkoristek | $\eta = \dfrac{A_{\text{koristno}}}{A_{\text{vloženo}}} = \dfrac{P_{\text{izh}}}{P_{\text{vh}}}$ |
| Toplota | $Q = m c \Delta T$ |
| Temperatura | $T\,[\text{K}] = t\,[^\circ\text{C}] + 273$ |

## Elektrika in magnetizem

| | |
|---|---|
| Električni tok | $I = \dfrac{e}{t}$ ($e$ naboj) |
| Ohmov zakon | $U = R I$ |
| Zaporedna vezava | $I = I_1 = I_2$, $\; U = U_1 + U_2$, $\; R = R_1 + R_2$ |
| Vzporedna vezava | $U = U_1 = U_2$, $\; I = I_1 + I_2$, $\; \dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ |
| Električna moč | $P = U I$ |
| Električno delo | $A = U I t = P t$, $\; 1\,\text{kWh} = 3{,}6 \cdot 10^6\,\text{J}$ |
