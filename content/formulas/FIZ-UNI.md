## Kinematika in dinamika

| | |
|---|---|
| Hitrost, pospešek | $\vec{v} = \dfrac{d\vec{r}}{dt}$, $\; \vec{a} = \dfrac{d\vec{v}}{dt}$, $\; a_t = \dfrac{dv}{dt}$, $\; a_r = \dfrac{v^2}{r}$ |
| Newtonovi zakoni | $\sum \vec{F} = \dfrac{d\vec{G}}{dt} = m\vec{a}$, $\; \vec{G} = m\vec{v}$, $\; \vec{F}_{12} = -\vec{F}_{21}$ |
| Sunek sile | $\int \vec{F}\,dt = \Delta\vec{G}$ |
| Delo, moč | $A = \int \vec{F} \cdot d\vec{s}$, $\; P = \vec{F} \cdot \vec{v}$ |
| Energija | $W_k = \dfrac{m v^2}{2}$, $\; \vec{F} = -\nabla W_p$, $\; A_{\text{nekons}} = \Delta(W_k + W_p)$ |
| Težišče | $\vec{r}_T = \dfrac{\sum m_i \vec{r}_i}{\sum m_i}$, $\; m\vec{a}_T = \sum \vec{F}_{\text{zun}}$ |
| Trki | prožni: ohranita se $\vec{G}$ in $W_k$; neprožni: le $\vec{G}$ |
| Gravitacija | $F = \dfrac{G m_1 m_2}{r^2}$, $\; W_p = -\dfrac{G m_1 m_2}{r}$, $\; v_1 = \sqrt{\dfrac{G M}{R}}$, $\; v_2 = \sqrt{\dfrac{2 G M}{R}}$ |
| Keplerjev 3. zakon | $\dfrac{T^2}{a^3} = \dfrac{4\pi^2}{G M}$ |

## Toga telesa

| | |
|---|---|
| Kotne količine | $\omega = \dfrac{d\varphi}{dt}$, $\; \alpha = \dfrac{d\omega}{dt}$, $\; v = \omega r$, $\; a_t = \alpha r$ |
| Navor, vrtilna količina | $\vec{M} = \vec{r} \times \vec{F}$, $\; \vec{\Gamma} = \vec{r} \times \vec{G} = J\vec{\omega}$, $\; \vec{M} = \dfrac{d\vec{\Gamma}}{dt} = J\vec{\alpha}$ |
| Vztrajnostni moment | $J = \sum m_i r_i^2 = \int r^2\,dm$; Steiner $J = J_T + m d^2$ |
| Tipični $J$ | palica (sredina) $\dfrac{m l^2}{12}$, palica (krajišče) $\dfrac{m l^2}{3}$, valj $\dfrac{m r^2}{2}$, obroč $m r^2$, krogla $\dfrac{2 m r^2}{5}$ |
| Energija vrtenja | $W_{\text{rot}} = \dfrac{J \omega^2}{2}$, $\; P = M \omega$ |
| Kotaljenje | $v_T = \omega r$, $\; W_k = \dfrac{m v_T^2}{2} + \dfrac{J_T \omega^2}{2}$ |

## Nihanje in valovanje

| | |
|---|---|
| Harmonično nihanje | $x = x_0 \sin(\omega t + \delta)$, $\; \ddot{x} + \omega_0^2 x = 0$ |
| Lastne frekvence | vzmet $\omega_0 = \sqrt{\dfrac{k}{m}}$, matematično nihalo $\omega_0 = \sqrt{\dfrac{g}{l}}$, fizično nihalo $\omega_0 = \sqrt{\dfrac{m g d}{J}}$, $LC$: $\omega_0 = \dfrac{1}{\sqrt{L C}}$ |
| Dušeno | $\ddot{x} + 2\beta\dot{x} + \omega_0^2 x = 0$, $\; x = x_0 e^{-\beta t}\sin(\omega t + \delta)$, $\; \omega = \sqrt{\omega_0^2 - \beta^2}$ |
| Vsiljeno | $x_0 = \dfrac{F_0 / m}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}$ |
| Valovanje | $u = u_0 \sin(k x - \omega t)$, $\; k = \dfrac{2\pi}{\lambda}$, $\; c = \lambda\nu = \dfrac{\omega}{k}$ |
| Valovna enačba | $\dfrac{\partial^2 u}{\partial t^2} = c^2 \dfrac{\partial^2 u}{\partial x^2}$ |
| Hitrost valovanja | struna $c = \sqrt{\dfrac{F}{\mu}}$, palica $c = \sqrt{\dfrac{E}{\rho}}$, plin $c = \sqrt{\dfrac{\kappa R T}{M}}$ |
| Stoječe valovanje | struna $l = n\dfrac{\lambda}{2}$, $\; \nu_n = \dfrac{n c}{2 l}$ |
| Dopplerjev pojav | $\nu' = \nu\,\dfrac{c \pm v_{\text{op}}}{c \mp v_{\text{vir}}}$ (zgornja znaka: približevanje) |
| Jakost zvoka | $j = \dfrac{P}{S}$, $\; L = 10 \log\dfrac{j}{j_0}\,\mathrm{dB}$, $\; j_0 = 10^{-12}\,\mathrm{W/m^2}$ |

## Termodinamika

| | |
|---|---|
| Plinska enačba | $p V = n R T = N k_B T$ |
| 1. zakon | $\Delta W_n = Q - A$, $\; A = \int p\,dV$ |
| Notranja energija idealnega plina | $W_n = n c_V T$; enoatomni $c_V = \dfrac{3}{2}R$, dvoatomni $c_V = \dfrac{5}{2}R$; $\; c_p - c_V = R$, $\; \kappa = \dfrac{c_p}{c_V}$ |
| Procesi | izotermni $A = n R T \ln\dfrac{V_2}{V_1}$; adiabatni $p V^\kappa = \text{konst.}$, $\; T V^{\kappa - 1} = \text{konst.}$ |
| Entropija | $dS = \dfrac{dQ}{T}$, $\; \Delta S = n c_V \ln\dfrac{T_2}{T_1} + n R \ln\dfrac{V_2}{V_1}$ |
| Izkoristek | $\eta = \dfrac{A}{Q_{\text{dov}}}$, Carnot $\eta_C = 1 - \dfrac{T_2}{T_1}$ |
| Kinetična teorija | $\dfrac{m_0 \overline{v^2}}{2} = \dfrac{3}{2} k_B T$, $\; v_{\text{ef}} = \sqrt{\dfrac{3 R T}{M}}$ |
| Prevajanje toplote | $P = \lambda S \dfrac{\Delta T}{d}$, $\; j = -\lambda \dfrac{dT}{dx}$ |
| Sevanje | $j = \sigma T^4$, Wien $\lambda_{\max} T = 2{,}898 \cdot 10^{-3}\,\mathrm{m\,K}$ |

## Elektrika in magnetizem

| | |
|---|---|
| Coulomb | $F = \dfrac{e_1 e_2}{4\pi\varepsilon_0 r^2}$, $\; \vec{E} = \dfrac{\vec{F}}{e}$ |
| Gauss | $\oint \vec{E} \cdot d\vec{S} = \dfrac{e_{\text{not}}}{\varepsilon_0}$ |
| Potencial | $U = -\int \vec{E} \cdot d\vec{s}$, $\; \vec{E} = -\nabla U$, točkast naboj $U = \dfrac{e}{4\pi\varepsilon_0 r}$ |
| Kondenzator | $C = \dfrac{e}{U}$, ploščati $C = \dfrac{\varepsilon\varepsilon_0 S}{d}$, $\; W = \dfrac{C U^2}{2}$, $\; w = \dfrac{\varepsilon_0 E^2}{2}$ |
| Tok, upor | $I = \dfrac{de}{dt}$, $\; U = R I$, $\; R = \zeta\dfrac{l}{S}$, $\; P = U I$ |
| Kirchhoffova zakona | $\sum I = 0$ v vozlišču, $\; \sum U = 0$ v zanki |
| $RC$ krog | $U_C = U_0\left(1 - e^{-t/RC}\right)$, $\; \tau = R C$ |
| Lorentzova sila | $\vec{F} = e(\vec{E} + \vec{v} \times \vec{B})$, na vodnik $\vec{F} = I\vec{l} \times \vec{B}$ |
| Biot–Savart | $d\vec{B} = \dfrac{\mu_0 I}{4\pi}\dfrac{d\vec{l} \times \vec{r}}{r^3}$; ravni vodnik $B = \dfrac{\mu_0 I}{2\pi r}$, tuljava $B = \dfrac{\mu_0 N I}{l}$ |
| Amperov zakon | $\oint \vec{B} \cdot d\vec{s} = \mu_0 I$ |
| Indukcija | $U_i = -\dfrac{d\Phi_m}{dt}$, $\; \Phi_m = \int \vec{B} \cdot d\vec{S}$, $\; U_i = -L\dfrac{dI}{dt}$, $\; W = \dfrac{L I^2}{2}$ |
| Izmenični tok | $X_L = \omega L$, $\; X_C = \dfrac{1}{\omega C}$, $\; Z = \sqrt{R^2 + (X_L - X_C)^2}$, $\; I_{\text{ef}} = \dfrac{I_0}{\sqrt{2}}$, $\; P = U_{\text{ef}} I_{\text{ef}} \cos\varphi$ |
| Maxwellove enačbe | $\nabla \cdot \vec{E} = \dfrac{\rho}{\varepsilon_0}$, $\; \nabla \cdot \vec{B} = 0$, $\; \nabla \times \vec{E} = -\dfrac{\partial\vec{B}}{\partial t}$, $\; \nabla \times \vec{B} = \mu_0\vec{j} + \mu_0\varepsilon_0\dfrac{\partial\vec{E}}{\partial t}$ |
| EM valovanje | $c = \dfrac{1}{\sqrt{\varepsilon_0\mu_0}}$, $\; E = c B$, $\; j = \dfrac{\varepsilon_0 c E_0^2}{2}$ |

## Optika

| | |
|---|---|
| Lomni zakon | $n_1 \sin\alpha_1 = n_2 \sin\alpha_2$, $\; n = \dfrac{c_0}{c}$, totalni odboj $\sin\alpha_m = \dfrac{n_2}{n_1}$ |
| Leče, zrcala | $\dfrac{1}{f} = \dfrac{1}{a} + \dfrac{1}{b}$, $\; M = -\dfrac{b}{a}$, zrcalo $f = \dfrac{r}{2}$, $\; \omega = \dfrac{1}{f}$ |
| Interferenca | dve reži ali uklonska mrežica $d \sin\vartheta = N\lambda$ (ojačitev), ena reža $b \sin\vartheta = N\lambda$ (minimum) |
| Tanka plast | $2 n d \cos\beta = \left(N + \tfrac{1}{2}\right)\lambda$ ojačitev (z enim odbojem na gostejši snovi) |
| Ločljivost | $\sin\vartheta_{\min} = 1{,}22\,\dfrac{\lambda}{D}$ |
| Polarizacija | Malus $j = j_0 \cos^2\varphi$, Brewster $\tan\alpha_B = \dfrac{n_2}{n_1}$ |

## Moderna fizika

| | |
|---|---|
| Foton | $W = h\nu = \dfrac{h c}{\lambda}$, $\; p = \dfrac{h}{\lambda}$, fotoefekt $h\nu = A_i + W_{k,\max}$ |
| De Broglie | $\lambda = \dfrac{h}{p}$ |
| Nedoločenost | $\Delta x\,\Delta p_x \ge \dfrac{\hbar}{2}$, $\; \hbar = \dfrac{h}{2\pi}$ |
| Comptonov pojav | $\Delta\lambda = \dfrac{h}{m_e c}(1 - \cos\vartheta)$ |
| Vodikov atom | $W_n = -\dfrac{13{,}6\,\mathrm{eV}}{n^2}$, $\; \dfrac{1}{\lambda} = R_\infty\left(\dfrac{1}{n_1^2} - \dfrac{1}{n_2^2}\right)$ |
| Schrödingerjeva enačba | $-\dfrac{\hbar^2}{2m}\dfrac{d^2\psi}{dx^2} + V\psi = W\psi$; neskončna jama $W_n = \dfrac{n^2 h^2}{8 m L^2}$ |
| Relativnost | $\gamma = \dfrac{1}{\sqrt{1 - v^2/c^2}}$, $\; t = \gamma t_0$, $\; l = \dfrac{l_0}{\gamma}$, $\; W = \gamma m c^2$, $\; W^2 = (p c)^2 + (m c^2)^2$ |
| Radioaktivnost | $N = N_0 e^{-\lambda t} = N_0\, 2^{-t/t_{1/2}}$, $\; t_{1/2} = \dfrac{\ln 2}{\lambda}$, $\; A = \lambda N$ |
| Vezavna energija | $W_v = (Z m_p + N m_n - m_j)\,c^2$ |
