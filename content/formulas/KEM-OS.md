## Zgradba atoma in periodni sistem

| | |
|---|---|
| Vrstno (atomsko) število | $Z$ = število protonov = število elektronov v atomu |
| Masno število | $A = Z + N$ ($N$ število nevtronov) |
| Zapis izotopa | $^{A}_{Z}\mathrm{X}$, npr. $^{12}_{6}\mathrm{C}$ |
| Elektroni po lupinah | največ $2$, $8$, $8$ (prve tri lupine pri prvih 20 elementih) |
| Skupina | število zunanjih (valenčnih) elektronov glavnih skupin |
| Perioda | število lupin z elektroni |

## Ioni in formule

| Kationi | Anioni |
|---|---|
| $\mathrm{H^+}$, $\mathrm{Na^+}$, $\mathrm{K^+}$, $\mathrm{NH_4^+}$, $\mathrm{Ag^+}$ | $\mathrm{F^-}$, $\mathrm{Cl^-}$, $\mathrm{Br^-}$, $\mathrm{I^-}$, $\mathrm{OH^-}$, $\mathrm{NO_3^-}$, $\mathrm{HCO_3^-}$ |
| $\mathrm{Mg^{2+}}$, $\mathrm{Ca^{2+}}$, $\mathrm{Ba^{2+}}$, $\mathrm{Zn^{2+}}$, $\mathrm{Cu^{2+}}$, $\mathrm{Fe^{2+}}$ | $\mathrm{O^{2-}}$, $\mathrm{S^{2-}}$, $\mathrm{SO_4^{2-}}$, $\mathrm{CO_3^{2-}}$ |
| $\mathrm{Al^{3+}}$, $\mathrm{Fe^{3+}}$ | $\mathrm{N^{3-}}$, $\mathrm{PO_4^{3-}}$ |

Formula ionske spojine: vsota nabojev je $0$, npr. $\mathrm{Al^{3+}}$ in $\mathrm{O^{2-}}$ → $\mathrm{Al_2O_3}$.

## Kemijske reakcije

| | |
|---|---|
| Zakon o ohranitvi mase | masa reaktantov $=$ masa produktov |
| Urejena enačba | enako število atomov vsakega elementa na obeh straneh, npr. $\mathrm{2H_2 + O_2 \rightarrow 2H_2O}$ |
| Eksotermna reakcija | sprošča toploto (gorenje, nevtralizacija) |
| Endotermna reakcija | porablja toploto (razkroj apnenca) |
| Nevtralizacija | kislina $+$ baza → sol $+$ voda, npr. $\mathrm{HCl + NaOH \rightarrow NaCl + H_2O}$ |
| Kovina in kislina | kovina $+$ kislina → sol $+$ vodik |
| Gorenje ogljikovodikov | ogljikovodik $+$ kisik → $\mathrm{CO_2}$ $+$ $\mathrm{H_2O}$ |

## Množina snovi in raztopine

| | |
|---|---|
| Množina snovi | $n = \dfrac{m}{M}$ |
| Število delcev | $N = n \cdot N_A$ |
| Molska masa | $M$ v $\mathrm{g/mol}$ = vsota relativnih atomskih mas $A_r$ |
| Masni delež | $w = \dfrac{m_{\text{topljenca}}}{m_{\text{raztopine}}}$, $\; m_{\text{raztopine}} = m_{\text{topljenca}} + m_{\text{topila}}$ |
| Masna koncentracija | $\gamma = \dfrac{m_{\text{topljenca}}}{V_{\text{raztopine}}}$ |
| Množinska koncentracija | $c = \dfrac{n}{V}$ |
| pH | kislo $< 7$, nevtralno $= 7$, bazično $> 7$ |

| | |
|---|---|
| Alkani | $\mathrm{C_nH_{2n+2}}$ (enojne vezi), npr. metan $\mathrm{CH_4}$ |

| Funkcionalne skupine | alkohol $\mathrm{-OH}$, karboksilna kislina $\mathrm{-COOH}$, ester $\mathrm{-COO-}$, amin $\mathrm{-NH_2}$ |
